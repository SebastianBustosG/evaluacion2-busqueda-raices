# Búsqueda de Raíces y Análisis de Convergencia

Este repositorio contiene la Evaluación 2 de Computación Numérica: "La raíz que se esconde", implementando métodos de búsqueda de raíces y analizando su convergencia.

## Integrantes
- Cristóbal Aguilera
- Sebastián Bustos

## Cómo montar el entorno de ejecución

Este proyecto utiliza un entorno virtual de Python (`venv`). Sigue estos pasos para configurarlo:

1. Clona el repositorio:
   ```bash
   git clone [https://github.com/SebastianBustosG/evaluacion2-busqueda-raices.git](https://github.com/SebastianBustosG/evaluacion2-busqueda-raices.git)
   cd evaluacion2-busqueda-raices
